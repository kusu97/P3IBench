# P³IBench Project Page

Official repository for the project page of:

**From Perception to Prediction and Intervention:  
Benchmarking Proactive Video Assistants in Real-Life Scenarios**

## Overview

P$^3$IBench is a benchmark for evaluating proactive video understanding under streaming visual input. It evaluates whether video assistants can perceive ongoing events, predict emerging risks, and provide timely interventions across diverse real-life scenarios.

The benchmark covers three complementary capabilities:  
Perception, Prediction, and Intervention.

For more details, please refer to our paper and project page.
